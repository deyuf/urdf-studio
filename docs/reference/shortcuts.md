# Mouse and keyboard

On macOS, use **⌘** where this page says **Ctrl**.

## 3D view

| Input | Action |
|---|---|
| Drag | Orbit |
| Right-drag | Pan |
| Scroll | Zoom |
| Click a part | Select the link and open the Inspector |
| Click empty space | Clear the selection |

## Source editor

| Keys | Action |
|---|---|
| F11 or Ctrl+Shift+F | Toggle full-screen source |
| Ctrl+S | Save — downloads in the browser, writes the file in VS Code |
| Ctrl+F | Find in the source |
| Ctrl+Space | Show completions (while editing) |

## Interface

| Keys | Action |
|---|---|
| Esc | Close an open menu, dialog or the tour |
| ← / → on the panel edge | Make the side panel wider or narrower |
| Home on the panel edge | Reset the side panel width |
| Tab | Move between controls; every control can be reached with the keyboard |

## Documentation site

| Keys | Action |
|---|---|
| Ctrl+K | Search the documentation |
